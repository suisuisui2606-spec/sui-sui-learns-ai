# sui-sui-learns-ai

A gentle learning journal for Suisui, exploring C, Python, and AI fundamentals step by step.

This project is not about rushing into complex programs. It is about turning the most basic and durable ideas in computing into small, friendly pieces that can be heard, seen, run, changed, and remembered.

## Project Direction

The journey starts with C because C is a good way to build a concrete sense of how programs work: instructions, data, memory, addresses, functions, and compilation.

Later, this repository may also include:

- Python: for expressing ideas quickly, building small tools, and exploring data.
- AI fundamentals: starting from simple ideas like models, data, training, prediction, and evaluation.
- Learning notes: small observations, questions, and discoveries along the way.

## How to Use This Project

1. Read `docs/00-学习地图.md` to get a map of the core C concepts.
2. Read `docs/01-胎教早教概念卡.md` to connect abstract ideas with everyday metaphors.
3. Run `examples/hello_suisui.c` as the first tiny C program.
4. After each learning session, write a short note in `journal/成长记录.md`.

## First Principle

Learning programming does not start with memorizing syntax. It starts with building a few simple mental models:

- A program is a clear sequence of instructions.
- Data has to live somewhere.
- Names help humans remember meaning and location.
- Types tell the computer how to interpret data.
- Functions make actions reusable.
- Addresses and references are about where things are.
- Tools translate, interpret, or execute the code humans write.

Take it slowly. Programming is a big world, but the beginning can be tiny: understand one word today, run one program tomorrow, and write down one new question after that.
